# Solara — pesquisa e reconstrução

Este repositório reúne a especificação de reconstrução da Solara e o trabalho local anterior. É um projeto independente; os contratos e a infraestrutura propostos não representam o código interno do serviço publicado.

| Caminho | Conteúdo |
|---|---|
| [`instructions.md`](instructions.md) | Especificação principal, evidências, arquitetura, esquema, API e ordem de implementação. |
| [`docs/solara-public-crawl.md`](docs/solara-public-crawl.md) | Evidências do rastreamento público e das capturas autenticadas fornecidas pelo usuário. |
| [`reconstrucao-solara/`](reconstrucao-solara/) | Documentos produzidos antes da especificação consolidada. |
| [`solara-medconsult/`](solara-medconsult/) | Base local de aplicação, backend, frontend, testes, diretrizes e documentação anteriores. |
| [`backup-antes-da-atualizacao/`](backup-antes-da-atualizacao/) | Cópia do frontend anterior à atualização local. |
| [`conteudo_raspado.md`](conteudo_raspado.md) | Conteúdo público coletado anteriormente para análise. |

Dependências instaladas, builds, ambientes locais, saídas de testes e o acervo de livros/documentos clínicos de `solara-medconsult/backend/acervo/` ficam fora do Git. A própria [documentação do acervo](solara-medconsult/backend/acervo/README.md) orienta a manter os livros fora do repositório. Use apenas dados sintéticos em desenvolvimento e testes.
