# Infectologia

Módulo clínico de Infectologia no mesmo fluxo e identidade visual do espec·IA·lidades.

- Conteúdo clínico: `backend/app/especialidades/infectologia.py`
- Diretrizes: `backend/diretrizes/infectologia/`
- Acervo RAG: `backend/acervo/infectologia/` (fora do git)
- Especialidade ativa: `ESPECIALIDADE=infectologia`
- Frontend: `NEXT_PUBLIC_ESPECIALIDADE=infectologia`

O módulo cobre abordagem sindrômica das infecções, diagnóstico microbiológico, uso seguro de
antimicrobianos, prevenção, controle de foco, vacinação, isolamento e sinais de gravidade.
