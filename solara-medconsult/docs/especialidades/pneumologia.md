# Pneumologia

Módulo clínico de Pneumologia no mesmo fluxo e identidade visual do espec·IA·lidades.

- Conteúdo clínico: `backend/app/especialidades/pneumologia.py`
- Diretrizes: `backend/diretrizes/pneumologia/`
- Acervo RAG: `backend/acervo/pneumologia/` (fora do git)
- Especialidade ativa: `ESPECIALIDADE=pneumologia`
- Frontend: `NEXT_PUBLIC_ESPECIALIDADE=pneumologia`

O módulo cobre doenças das vias aéreas, parênquima pulmonar, pleura, circulação pulmonar,
sono e troca gasosa. A resposta clínica continua sendo uma sugestão para revisão do profissional.
